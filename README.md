## 1. Project Introduction

This repository contains the final independent project for the GEOL0069 AI4EO module. The core objective of this study is to map and interpret rapid tropical deforestation dynamics within Rondônia, Brazil, over a critical four-year window spanning 2019 to 2022. To achieve this, high-resolution imagery from the Sentinel-2 satellite constellation is processed to capture subtle spectral variations associated with canopy loss. The predictive framework relies on a Random Forest classifier, a supervised ensemble method—trained against target labels from the Hansen Global Forest Change dataset. Furthermore, the pipeline integrates TreeSHAP to dismantle the "black box" nature of the model, delivering pixel-level transparency regarding which spectral bands and indices drive the classification of forest loss.
